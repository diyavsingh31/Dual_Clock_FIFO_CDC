# Asynchronous Dual Clock FIFO Design in Verilog

## Overview

This project implements an asynchronous dual clock FIFO using Verilog HDL. The FIFO enables data transfer between two independent clock domains using clock domain crossing (CDC) techniques.

The design uses Gray-coded read and write pointers, two-flop synchronizers, and separate read/write control logic to safely transfer data between asynchronous clocks.

---

## Features

- Synthesizable Verilog RTL design
- Independent read and write clock domains
- Parameterized data width and FIFO depth
- Gray code based pointer synchronization
- Two-flop CDC synchronizers
- FIFO full and empty flag generation
- Dual-clock memory implementation
- Verilog-based functional verification

---

## Architecture

The design consists of the following modules:

### FIFO_CDC.v

Top-level module that integrates:

- FIFO memory
- Write pointer logic
- Read pointer logic
- Clock domain synchronizers


### a_ptr.v

Write pointer controller:

- Maintains binary write pointer
- Generates Gray-coded write pointer
- Generates FIFO write address
- Generates full condition


### b_ptr.v

Read pointer controller:

- Maintains binary read pointer
- Generates Gray-coded read pointer
- Generates FIFO read address
- Generates empty condition


### fifo_mem.v

FIFO storage module:

- Dual clock memory
- Write operation controlled by write clock
- Read operation controlled by read clock


### RW.v and WR.v

CDC synchronizer modules:

- Transfer Gray-coded pointers between clock domains
- Implement two-stage flip-flop synchronization

---

## Clock Domain Crossing

The write and read sides operate on independent clocks. Since binary counters can have multiple bit transitions, directly transferring them between clock domains can cause incorrect synchronization.

The design converts binary pointers to Gray code before synchronization.

Binary to Gray conversion
The synchronized Gray pointer is passed through two flip-flops to reduce metastability probability.

---

## FIFO Operation

### Write Operation

Data is written when:
a_en = 1 && full = 0
The write pointer increments after a successful write operation.

---

### Read Operation

Data is read when:
b_en = 1 && empty = 0
The read pointer increments after a successful read operation.

---

## FIFO Status Generation

### Full Condition

The FIFO full flag is generated by comparing the next write pointer with the synchronized read pointer.
full = 1
when the FIFO cannot accept additional data.

---

### Empty Condition

The FIFO empty flag is generated by comparing the read pointer with the synchronized write pointer.
empty = 1
when no unread data is available.

## Verification

A Verilog testbench is used to verify FIFO functionality.

The following test cases are included:

- Reset operation
- Single write and read operation
- Multiple write and read operations
- FIFO full condition
- Overflow attempt
- FIFO empty condition
- Underflow attempt
- Simultaneous read and write operations

The testbench uses different clock periods for read and write domains to verify asynchronous clock operation.
